Key Concepts

table join

  • inner_join(): Keep matching records only.
  • left_join(): Keep all left-table records; unmatched values become NA.
  • full_join(): Keep all records from both tables.

Spatial Data and CRS

  • get_acs(..., geometry = TRUE): Return census data with spatial geometry.
  • Sticky geometry: Geometry stays attached during table operations; remove with st_drop_geometry().
  • CRS: Defines how coordinates represent locations.
  • Geographic CRS: Longitude and latitude, measured in degrees.
  • Projected CRS: Planar coordinates, usually measured in meters or feet.
  • NAD83: Common datum for North American data.
  • WGS84: Global datum used by GPS.

Map Projections

  • Types: Cylindrical, conic, and planar/azimuthal.
  • Conformal: Preserves local angles and shapes.
  • Equal-area: Preserves area.
  • Equidistant: Preserves distances along specific lines or from specific points.
  • Azimuthal: Preserves directions from a central point.
  • UTM: Uses 60 zones and meter-based coordinates, normally positive within the appropriate zone.

Function Key purpose

st_touches(x, y) Test whether geometries touch without interior overlap
